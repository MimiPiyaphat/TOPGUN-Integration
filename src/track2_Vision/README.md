# Vision AI – Smart Robusta Coffee
### ระบบปัญญาประดิษฐ์สำหรับวิเคราะห์และจำแนกประเภทเมล็ดกาแฟโรบัสต้า

## 1. ภาพรวม (Overview)

ส่วนนี้เป็นการพัฒนาระบบปัญญาประดิษฐ์ด้านการประมวลผลภาพ (Computer Vision) สำหรับวิเคราะห์และจำแนกประเภทเมล็ดกาแฟโรบัสต้าจังหวัดชุมพร โดยใช้เทคนิค Machine Learning และ Deep Learning เพื่อช่วยตรวจสอบลักษณะและข้อบกพร่องของเมล็ดกาแฟ

ระบบจะรับภาพเมล็ดกาแฟมาประมวลผล จำแนกประเภท ตรวจจับตำแหน่ง และแบ่งส่วนพื้นที่ของเมล็ดกาแฟ ก่อนนำผลลัพธ์ไปใช้ร่วมกับระบบส่วนอื่นของโครงการ

## 2. วัตถุประสงค์ (Objectives)

- เตรียมชุดข้อมูลภาพเมล็ดกาแฟสำหรับใช้ฝึกสอนโมเดล
- พัฒนาโมเดลสำหรับจำแนกประเภทเมล็ดกาแฟ 7 ประเภท
- พัฒนาระบบตรวจจับตำแหน่งของเมล็ดกาแฟ
- พัฒนาระบบแบ่งส่วนพื้นที่ของเมล็ดกาแฟ
- ทดสอบโมเดลกับภาพเมล็ดกาแฟที่มีการผสมหลายประเภท
- ประเมินประสิทธิภาพของโมเดลและเตรียมผลลัพธ์สำหรับนำไปใช้งานบน Raspberry Pi 5

## 3. ประเภทของเมล็ดกาแฟ (Coffee Bean Classes)

ระบบใช้ประเภทของเมล็ดกาแฟทั้งหมด 7 ประเภท ได้แก่

| ลำดับ | Class | คำอธิบาย |
|---|---|---|
| 1 | Good | เมล็ดกาแฟปกติ |
| 2 | Shell | เมล็ดกาแฟลักษณะ Shell |
| 3 | Full Black | เมล็ดกาแฟดำทั้งเมล็ด |
| 4 | Hull / Husk | เปลือกกาแฟ |
| 5 | Broken / Chipped / Cut | เมล็ดกาแฟแตก บิ่น หรือถูกตัด |
| 6 | Parchment / Pergamino | เมล็ดกาแฟที่ยังมีเยื่อกะลา |
| 7 | Immature / Unripe | เมล็ดกาแฟที่ยังไม่สุกเต็มที่ |

*หมายเหตุ: การกำหนดป้ายกำกับและความหมายของแต่ละ Class ให้ยึดตามชุดข้อมูลและข้อกำหนดของการแข่งขัน*

## 4. ขั้นตอนการพัฒนา (Development Workflow)

### ขั้นตอนที่ 1: เตรียมชุดข้อมูล (Dataset Preparation)

- รวบรวมภาพเมล็ดกาแฟทั้ง 7 ประเภท
- ตรวจสอบความถูกต้องของภาพ
- กำหนด Label ให้ตรงกับประเภทของเมล็ดกาแฟ
- จัดเตรียมข้อมูลสำหรับฝึกสอนและทดสอบโมเดล

### ขั้นตอนที่ 2: การจำแนกประเภท (Classification)

พัฒนาโมเดลเพื่อจำแนกภาพเมล็ดกาแฟว่าเป็นประเภทใดจากทั้งหมด 7 ประเภท โดยเริ่มจากการทดสอบกับภาพเมล็ดกาแฟทีละเมล็ด

### ขั้นตอนที่ 3: การตรวจจับวัตถุ (Object Detection)

พัฒนาโมเดลเพื่อตรวจจับตำแหน่งของเมล็ดกาแฟภายในภาพ โดยแสดงกรอบสี่เหลี่ยม (Bounding Box) พร้อมระบุประเภทของเมล็ดกาแฟที่ตรวจพบ

### ขั้นตอนที่ 4: การแบ่งส่วนภาพ (Segmentation)

พัฒนาโมเดลเพื่อแบ่งพื้นที่ของเมล็ดกาแฟออกจากพื้นหลัง โดยศึกษาการแบ่งส่วนภาพตามขอบเขตและรูปร่างของเมล็ดกาแฟ

### ขั้นตอนที่ 5: ทดสอบกับเมล็ดกาแฟหลายประเภท (Mixed Bean Testing)

นำโมเดลมาทดสอบกับภาพที่มีเมล็ดกาแฟหลายประเภทปะปนกัน เพื่อตรวจสอบความสามารถในการจำแนกและวิเคราะห์เมล็ดกาแฟในสถานการณ์จริง

### ขั้นตอนที่ 6: ประเมินผลและเตรียมใช้งาน (Evaluation & Deployment Preparation)

- ตรวจสอบความแม่นยำของโมเดล
- วิเคราะห์ข้อผิดพลาดในการจำแนก
- ทดสอบความเร็วในการประมวลผล
- เตรียมโมเดลสำหรับส่งต่อให้ส่วน Raspberry Pi 5 นำไปติดตั้งและใช้งาน
