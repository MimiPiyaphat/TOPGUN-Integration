# แผนการดำเนินโครงการ (Project Plan)

## Smart Robusta Coffee – TESA Top Gun Rally #20

## 1. ภาพรวมโครงการ (Project Overview)

โครงการนี้มีเป้าหมายในการพัฒนาแพลตฟอร์ม AIoT สำหรับประเมินคุณภาพกาแฟโรบัสต้าจังหวัดชุมพร และนำเทคโนโลยีปัญญาประดิษฐ์มาประยุกต์ใช้กับการซื้อขายกาแฟ

ระบบประกอบด้วย 3 ส่วนหลัก ได้แก่

- **Track 1 – ระบบสมองกลฝังตัว (Embedded System):** ใช้ ESP32 และเซนเซอร์ในการวัดความชื้นของเมล็ดกาแฟ
- **Track 2 – ปัญญาประดิษฐ์ด้านภาพ (Vision AI):** ใช้เทคโนโลยี Computer Vision ในการจำแนกประเภทและตรวจจับข้อบกพร่องของเมล็ดกาแฟ
- **Track 3 – ตัวแทนปัญญาประดิษฐ์ (AI Agent):** พัฒนา AI Agent เพื่อวิเคราะห์ข้อมูลล็อตกาแฟและตัดสินใจซื้อขายในตลาดจำลอง

เป้าหมายหลักคือการนำเทคโนโลยีทั้งหมดมาเชื่อมต่อและทำงานร่วมกันเป็นระบบเดียว

## 2. วัตถุประสงค์ของโครงการ (Project Objectives)

- พัฒนาระบบวัดความชื้นของเมล็ดกาแฟด้วย ESP32 และเซนเซอร์
- จำแนกเมล็ดกาแฟออกเป็น 7 ประเภทด้วย Vision AI
- นำโมเดล Vision AI ไปใช้งานบน Raspberry Pi 5
- พัฒนา AI Agent เพื่อทำงานร่วมกับระบบตลาดซื้อขายกาแฟ
- เชื่อมต่อและทดสอบการทำงานร่วมกันของทุกส่วนในระบบ

## 3. ขอบเขตการดำเนินงาน (Project Scope)

### Track 1 – ระบบสมองกลฝังตัว (Embedded System)

- พัฒนาโปรแกรมควบคุมการทำงานของ ESP32 (Firmware)
- เชื่อมต่อเซนเซอร์วัดความชื้นและอ่านค่าจากเซนเซอร์
- ทดสอบความถูกต้องและความเสถียรของค่าที่วัดได้
- เตรียมข้อมูลสำหรับนำไปเชื่อมต่อกับระบบส่วนอื่น

### Track 2 – ปัญญาประดิษฐ์ด้านภาพ (Vision AI)

- เตรียมชุดข้อมูลเมล็ดกาแฟ 7 ประเภท
- ฝึกสอนโมเดลจำแนกประเภทเมล็ดกาแฟ (Classification)
- พัฒนาระบบตรวจจับวัตถุ (Object Detection) และการแบ่งส่วนภาพ (Segmentation)
- ทดสอบโมเดลกับเมล็ดกาแฟที่มีการผสมหลายประเภท
- ประเมินประสิทธิภาพของโมเดล

### Track 2 – Raspberry Pi 5

- เตรียมและติดตั้งระบบบน Raspberry Pi 5 (RAM 8GB)
- นำโมเดล Vision AI ที่ผ่านการฝึกสอนไปติดตั้งและใช้งาน
- ทดสอบความเร็วในการประมวลผลของโมเดล
- เตรียมผลลัพธ์จากการประมวลผลสำหรับเชื่อมต่อกับระบบส่วนอื่น

### Track 3 – ตัวแทนปัญญาประดิษฐ์ (AI Agent)

- ศึกษาโค้ดเริ่มต้น (Starter Code) ที่ผู้จัดเตรียมไว้
- ทำความเข้าใจ API ของระบบตลาดซื้อขายกาแฟ
- พัฒนากระบวนการทำงานแบบ Observe–Think–Act
- ทดสอบกลยุทธ์การเสนอราคาและการซื้อขาย
- ประเมินผลการทำงานของ AI Agent

## 5. ลำดับการทำงานของระบบ (System Workflow)

1. ESP32 อ่านค่าความชื้นของเมล็ดกาแฟจากเซนเซอร์
2. กล้องถ่ายภาพเมล็ดกาแฟ
3. Vision AI วิเคราะห์และจำแนกคุณภาพของเมล็ดกาแฟ
4. Raspberry Pi 5 ประมวลผลโมเดล AI ที่ผ่านการฝึกสอน
5. ระบบจัดเตรียมข้อมูลของล็อตกาแฟ
6. AI Agent วิเคราะห์ข้อมูลจากตลาดและตัดสินใจดำเนินการซื้อขาย

*หมายเหตุ: การส่งข้อมูลและการเชื่อมต่อระหว่างระบบจะต้องเป็นไปตามข้อกำหนดของการแข่งขัน*

## 10. การติดตามความคืบหน้าของงาน (Progress Tracking)

สมาชิกทุกคนต้องอัปเดตสถานะความคืบหน้าของงานที่ตนเองรับผิดชอบอย่างสม่ำเสมอ

สถานะของงานที่ใช้ในการติดตาม ได้แก่

- **Not Started:** ยังไม่ได้เริ่มดำเนินงาน
- **In Progress:** กำลังดำเนินงาน
- **Testing:** อยู่ระหว่างการทดสอบ
- **Completed:** ดำเนินงานเสร็จสิ้น
- **Blocked:** ติดปัญหาและไม่สามารถดำเนินงานต่อได้

ผู้จัดการโครงการ (Project Manager) มีหน้าที่ติดตามความคืบหน้าของงาน ตรวจสอบปัญหาที่เกิดขึ้น ประสานงานระหว่างสมาชิก และดูแลให้การดำเนินโครงการเป็นไปตามแผนที่กำหนดไว้
